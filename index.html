ByteShield Uploader (internal tool)

ByteShield Uploader is a private command-line tool used only by the ByteShield channel owner to upload ByteShield's own original videos to ByteShield's own YouTube channels. It is not a public app, has no sign-up and has no other users.

  1. The owner produces a video on his own computer.
  2. The tool signs in with the owner's Google account through Google's standard OAuth consent screen (scope: youtube.upload only).
  3. It calls videos.insert of the YouTube Data API v3 to upload the video to the owner's channel, with its title, description and tags.
  4. It saves only the returned video ID locally, to add a link to the full video in the related Shorts.

It does not read, display, store or analyse any other YouTube data or any data of other users.
