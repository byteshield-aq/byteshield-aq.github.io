Privacy Policy

Last updated: 31 October 2026

What this app is

"ByteShield Uploader" is an internal tool used only by the ByteShield channel owner to upload ByteShield's own original videos to ByteShield's own YouTube channels through the YouTube API Services. It is not offered to the public and has no other users.

YouTube API Services

ByteShield Uploader uses YouTube API Services. By using it, users agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Data we access, use and store

  • The only Google permission requested is https://www.googleapis.com/auth/youtube.upload, used to upload our own videos to our own channels.
  • The OAuth token for our own account is stored only on our own computer, so the tool can upload without signing in every time.
  • The only API data we keep is the ID of each video we upload, stored locally, to link our Shorts to the full video.

Data we do not collect or share

We do not access, collect, store, sell or share any data of other YouTube users or viewers. We do not share any data with third parties. This website uses no cookies, no analytics and no tracking.

Google API Services User Data Policy

ByteShield Uploader's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

Access can be revoked at any time from the Google security settings page: https://security.google.com/settings/security/permissions. Revoking access invalidates the stored token; the locally stored token and video IDs can then be deleted by the owner, and are deleted on request within 7 days.
